## 产品定位

MyHEBNU 是河北师范大学的**非官方 Android 教务助手**，把 ZFSOFT 教务系统封装为 Material Design 3 界面，让用户在手机上更快地查看课表、成绩、空教室与考试安排。

| 项 | 内容 |
| --- | --- |
| 主用户 | 作者本人及河北师大在校生；当前按单用户设计，无多账号切换 |
| 平台 | Android 12+（API 31+），手机竖屏为主 |
| 分发 | GitHub Releases 签名 APK |
| 定位 | 个人学习项目，不替代学校官方系统 |

## 目标与非目标

### 目标

- **更快**：首页启动零联网；课表/成绩再次进入缓存优先，避免每次等待网络。
- **更清楚**：课表周视图、成绩按学期折叠、考试倒计时、空教室分页筛选。
- **更贴合本校**：三学期（含小学期）、双校区、13 节真实节次、教务真实时间。
- **可离线查看**：课表/成绩/考试有本地缓存；断网时优先展示已有数据。

### 非目标

- 不做多学校适配；接口与学期编码按河北师大定制。
- 不做云端同步、账号体系、社交/分享社区。
- 不提供浏览器登录兜底（WebView fallback 已移除，#23）。
- 不承诺与教务系统实时一致；以本地缓存 + 手动刷新为准。
- 不做桌面端/网页版。

## 用户场景

| # | 场景 | 期望结果 |
| --- | --- | --- |
| 1 | 早上打开 App 看今天课程 | 首页直接显示下一节课/正在上课，无网络等待 |
| 2 | 课间找空教室自习 | 首页卡片 → 选校区/楼/周次/星期/节次 → 分页结果 |
| 3 | 期末查成绩 | 首页成绩卡 → 按学期展开 → GPA/加权均分/趋势/明细 |
| 4 | 考试周确认安排 | 首页考试卡 → 当前学期考试列表 + 倒计时 |
| 5 | 学期结束想提前看下学期课表 | 课表页学期末浮层 → 查询/查看下学期 → 可返回本学期 |
| 6 | 忘记当前教学周/学期设置不对 | 设置 → 学期设置，按教务周次映射重设开学日 |
| 7 | 桌面看下一节课 | 添加 2×2/4×2/4×4 Widget，自动跨日显示明日课程 |
| 8 | 上课/考试前收到提醒 | 课前 15 分钟、考前 1 天/1 小时通知 |

## UI/UX 规范

- **设计语言**：Material Design 3；动态取色（Android 12+）；自定义 seed hue 时优先自定义色板。
- **导航**：单首页四卡入口；子页顶部返回箭头；系统返回手势由 `BackHandler` 接管；无抽屉、无底部栏。
- **选择器**：离散选项用 `ExposedDropdownMenuBox`（选项多）或 `SingleChoiceSegmentedButtonRow`（选项少）；数值用 `Slider`；**禁止自研滚轮**。
- **课表**：周一–周五默认 5 列，开启周末为 7 列；节次列 36dp（5 列）/28dp（7 列）；课程卡四周 2dp 呼吸；课名行数按卡片高度自适应。
- **状态表达**：加载用进度指示；空态给明确文案；错误给重试；一次性结果用 Toast/Snackbar。
- **卡片**：设置页胶囊卡片（16dp 圆角、elevation=0）；首页 ElevatedCard；课程/考试色条遵循 MD3 tonal palette。
- **文案**：中文为主；通知/提醒文案走字符串资源；新增文案同步 `values-en`。

## 数据流

```text
用户操作 → ViewModel(UiState) → Repository
                                  ├─ Room（缓存）
                                  ├─ DataStore（偏好/节次/首页均分）
                                  └─ Retrofit（教务 API）
                                       └─ 成功 → 写缓存 → Flow 驱动 UI
                                       └─ 失败 → 已有缓存则展示 + 提示；否则错误态
```
